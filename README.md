# Nokia 603 — продающий сайт

Живая версия: https://mazamaka.github.io/nokia-603-site/

Статический сайт в стиле `DESIGN.md` («Midnight hardware gallery»): чёрная сцена, SF Pro/Inter, синие pill-кнопки, рамки 28 px. Без сборки и зависимостей.

```bash
python3 -m http.server 8603 --directory /Users/admin/PET/nokia-603-site
```

Откройте http://localhost:8603.

## Страницы

| Файл | Что внутри |
|---|---|
| `index.html` | Обзор: герой, карусель «Коротко о главном», дизайн, экран, производительность, «классика» (3,5 мм, съёмная батарея, FM, microSD, кнопки), выбор цвета панели, сравнение с 6 телефонами, комплектация, «почему у нас», честный FAQ |
| `specs.html` | Полные характеристики по официальным спецификациям Nokia с чертежом габаритов |
| `buy.html` | Конфигуратор: состояние, цвет корпуса, панель, допы → корзина |
| `checkout.html` | Оформление: контакты, Новая Почта (отделение, почтомат или курьер), оплата. Данные карты не собираются |

Корзина хранится в `localStorage`. Выезжающая панель корзины работает на всех страницах.

## Что заменить перед запуском

- Цены, условия оплаты частями и гарантии — плейсхолдеры магазина. Цены заданы в `assets/js/site.js` (`CONDITIONS`, `ADDONS`, `COVER_PRICE`) и продублированы текстом в HTML.
- Телефон в подвале: `+380 (00) 000-00-00`.
- Отправка заказа: пока включён демо-режим (`DEMO_ORDERS = true` в `site.js`). Заказ только логируется в консоль, на оформлении висит пометка «Демо-режим». После подключения CRM (место помечено `TODO(canonical)`) выставьте `false`.
- Деплой: GitHub Pages из ветки `main`. Папки `_render/` и `_preview/` Jekyll не публикует (начинаются с «_»), в репозитории они остаются как исходники.

## Картинки

Все продуктовые кадры — рендеры Blender 5.2 (Cycles). Модель Nokia 603 построена по размерам из спецификации (113,5 × 57,1 × 12,7 мм) и официальной схеме клавиш из руководства пользователя Nokia. Экран — настоящий рабочий стол Nokia Belle, выпрямленный из фото реального аппарата.

Перерендерить, например чтобы поменять цвет или свет:

```bash
cd /Users/admin/PET/nokia-603-site/_render
python3 tex.py
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup -P scene.py -- hero_black lineup --samples 128
python3 export.py
```

- `tex.py` — текстуры.
- Названия кадров — ключи `SHOTS` в `scene.py`.
- `export.py` пишет WebP в `assets/img`.
